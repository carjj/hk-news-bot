1

開 Telegram Bot，拎 Token

呢條 Token 就係 bot 嘅「密碼」，之後放落 GitHub

  1. 打開 Telegram，搜尋 @BotFather（認住有藍色 ✔️ 官方標記）
  2. 撳 START，然後傳呢句：/newbot
  3. 佢會問你 bot 嘅名 → 例如 HK 新聞快報
  4. 再問 username → 例如 hk_news_2026_bot
    ⚠️ 一定要 _bot 結尾，而且唔可以同人重複
  5. 成功之後佢會俾一條長長嘅 Token 你 → 即刻抄低！

⚠️ 注意 唔好將 Token 傳去任何人、唔好擺上公開地方。第 8 步我們會用加密嘅 Secrets 存放。
2

開一個 Channel 用嚟收新聞

新聞會推送去呢個 Channel；亦可以推去群組或自己

  1. Telegram 左上角（iPhone）／右下角鉛筆（Android）→ New Channel
  2. 改名，例如 每日中文新聞，下一步
  3. 一定要揀 Public Channel 並設定一個 username，例如 @hk_news_daily
    💡 揀 Public 係因為可以直接用 @username 做推送目標，唔使搵數字 ID，最簡單。
    你唔宣傳嘅話，實際上冇人會搵到你個 Channel。
  4. 開好之後：撳 Channel 名 → Administrators → Add Admin
  5. 搜尋你頭先開嘅 bot（@hk_news_2026_bot）→ 加佢
  6. 權限嗰度最少要開 Post Messages，之後撳 ✓

3

拎 Chat ID（推送目標地址）

話畀程式知推去邊

如果你第 2 步開咗 Public Channel，呢步極簡單：

✅ 直接用 username Chat ID 就係 @hk_news_daily（即係你 Channel 嘅 username，連埋 @ 字）
→ 直接跳去第 4 步。

如果想推去私人 Channel / 群組 / 自己，就要搵數字 ID：

  1. Telegram 搜尋 @RawDataBot → 撳 START
  2. 返去你個 Channel，Forward（轉發）一條訊息 去 @RawDataBot
  3. 佢會回覆一大堆資料，搵呢一行：
"chat": { "id": -1001234567890, "title": "每日中文新聞", "type": "channel" }

呢個 -1001234567890 就係 Chat ID。負號同全部數字都要抄齊。

⚠️ 群組 ID 一定係負數 例如 -1001234567890，前面個 - 千祈唔好漏。
個人 ID 就係正數，例如 987654321。
💡 想同時推去幾個地方？ 用逗號分隔就得：@hk_news_daily,-1001234567890,987654321
4

開 GitHub 帳號

免費，用嚟每小時自動跑程式

  1. 去 github.com/signup
  2. 輸入 email → 設定密碼 → 設定 username（例如 hk-news-lover）
  3. 驗證電郵（收件匣撳驗證連結）
  4. 登入完成 ✅
💡 已經有帳號？直接去第 5 步。
5

開一個新 Repository（放程式嘅地方）

可以當係一個雲端資料夾

  1. 登入 GitHub，右上角 + → New repository
  2. Repository name 填 hk-news-bot
  3. 揀 ● Public（免費無限 Actions 分鐘數）
  4. 全部剔選框都唔好剔（唔好加 README、.gitignore、license）
  5. 撳綠色 Create repository

上傳檔案

把 news-bot.zip 解壓，成個資料夾拖入去

先喺電腦度準備：

  1. 下載我畀你嘅 news-bot.zip
  2. 解壓（Windows 右鍵 → 解壓縮全部；Mac 撳兩下）
  3. 會出一個 news-bot 資料夾

然後上傳（方法 A：網頁，最簡單）：

  1. 喺第 5 步開好嘅空白 repo 頁面，撳中間藍字 uploading an existing file
  2. 打開 news-bot 資料夾，撳 Ctrl+A / Cmd+A 全選入面所有嘢 （包括 .github、newsbot、config.yaml…）
  3. 一次過拖入去網頁個虛線框
  4. 等佢上傳完（左下角會顯示進度）

8

設定 Secrets（安全咁放 Token）

加密存放，log 入面會自動變 ***，唔會洩漏

  1. repo 頂部撳 Settings（右上角齒輪）
  2. 左邊選單拉落去：Secrets and variables → Actions
  3. 撳綠色 New repository secret
  4. 填第一個：
    NameTELEGRAM_BOT_TOKEN
    Secret貼上第 1 步嘅 Token
    撳 Add secret
  5. 再撳多次 New repository secret，填第二個：
    NameTELEGRAM_CHAT_IDS
    Secret貼上第 3 步嘅 Chat ID（例如 @hk_news_daily）
    撳 Add secret

❌ 兩個最常見錯誤 1. Name 打錯字／多咗空格（一定要全大寫、底線：TELEGRAM_BOT_TOKEN）
2. 放咗去「Variables」而唔係「Secrets」→ Variable 唔係加密，而且我個 workflow 係讀 Secrets 嘅
💡 想改設定（數量、時間、版塊）？ 同一頁撳 Variables 分頁 → New repository variable，可加：
MAX_TOTAL=14（每次最多幾單）　MAX_AGE_HOURS=12
SECTIONS=hk,world　QUIET_HOURS=0-6（深夜唔推）
MODE=digest 或 individual
9

啟動 GitHub Actions

等 GitHub 準許自動執行你嘅程式

  1. repo 頂部撳 Actions
  2. 你會見到一段提示：
    Workflows aren't being run on this fork / repository
    Workflows are disabled in this repository.
    I understand my workflows, go ahead and enable them
  3. 撳嗰個綠色制 ✅
  4. 左邊選單會見到 每小時中文新聞推送（即係 hourly-news.yml 入面寫嘅名）
10

試跑 + 驗收 🎉

手動 Run 一次，睇吓 Telegram 收唔收到

  1. Actions 頁 → 左邊撳 每小時中文新聞推送
  2. 右邊撳 Run workflow ▾ → 再撳綠色 Run workflow
  3. 等 30–60 秒，下面會出一個黃點／綠剔嘅運行記錄，撳入去
  4. 撳 抓取並推送新聞 嗰個步驟，會見到類似呢啲 log：
INFO 抓取 22 個新聞來源… INFO 共抓到 1125 則原始新聞 INFO 過濾：剩 438 則（剔走：非中文 6／太舊 604／廣告 37／黑名單媒體 39／太短 1） INFO 重新分類：香港 193 則 ／ 國際 245 則 INFO 合併後共 404 單新聞（原本 420 則報道） INFO 扣除已推送，剩 404 單新新聞 INFO ✅ 已推送 2 則訊息到 1 個目標 INFO 完成：推送 12 單新聞
✅ 見到「已推送」= 成功！ 開 Telegram 睇你個 Channel，應該已經收到一份中文新聞快報。
❌ 如果見到紅色 ❌ 或者 error？ 撳開 log 睇紅字，對照下面：
401: Unauthorized → Token 錯咗／抄漏 → 返第 8 步重新貼
403: Forbidden: bot is not a member → Bot 未做 Channel Admin → 返第 2 步
400: chat not found → Chat ID 錯 → 返第 3 步（Public Channel 記得連 @）
設定錯誤：缺少 TELEGRAM_… → Secrets 名打錯 → 返第 8 步
其他 → 撳 log 右上角「Copy raw log」傳畀我，我幫你睇
🕐 之後會點？ 程式已經設定咗 cron: "8 * * * *"，即係 UTC 每小時第 8 分 ＝ 香港時間每小時嘅 08 分（例如 13:08、14:08、15:08…）自動跑一次。
GitHub 繁忙時間可能會延遲 5–30 分鐘，屬正常。

之後想改嘢？

全部唔使重新設定 Actions，改完 push 就生效

  • 想加／減新聞來源 → GitHub 開 config.yaml → 鉛筆制編輯 → 改 sources: → Commit
  • 想開財經／科技版塊 → config.yaml 嘅 sections: 把 enabled: false 改做 true
  • 想深夜唔好嘈 → Settings → Variables 加 QUIET_HOURS = 0-6
  • 想改推送時間 → 開 .github/workflows/hourly-news.yml 改 cron
    格式：分 時 日 月 星期（UTC）。香港時間減 8 小時。 例：香港 09:00 → UTC 01:00 → cron: "0 1 * * *"
  • 想淨係推香港 → Variables 加 SECTIONS = hk
  • 想多啲／少啲新聞 → Variables 加 MAX_TOTAL = 20
🎉 搞掂！ 之後你咩都唔使做，每小時自動有新鮮中文新聞送到 Telegram。
